God's Eye View is an open source 3D globe that runs in your browser. It shows live flights, ships, satellites, weather, earthquakes and public cameras in one place. Click on any of them to follow it.

What it is

One globe for everything Earth is already broadcasting

Aircraft transponders, ship beacons, satellite orbits, seismographs and public webcams each show part of what is happening on Earth. This project puts them all on one photorealistic globe. You can zoom from the whole planet down to a single plane, ship or street. It was made by Bilawal Sidhu and grew out of his YouTube series of the same name.

It looks like a spy agency tool, but every feed is public and you can read every line of the code. A few layers are estimates, such as simulated road traffic and approximate camera angles, and the app labels them.

Features

What you can do with it

The main features, in plain terms.

Track anything

Click a plane, ship, satellite or camera. The view locks on, draws a fading trail and shows its details.

Ride in the cockpit

Jump inside a tracked flight and watch the terrain pass below. When you get close, planes, ships and trains appear as 3D models.

Ask the planet

Ask questions out loud, such as "what satellites pass over me tonight?", and the answer appears on the globe. This needs an OpenAI key.

Weather in 4D

Forecast winds, rain radar, lightning and cyclone tracks with forecast cones. You can scrub backwards through recent cloud images.

Fresh satellite photos

Draw a box around a wildfire or flood and it fetches recent Sentinel-2 images, laid over the 3D terrain.

Sensor modes

Switch the view to thermal (FLIR), night vision, CRT or a military-style display, with boxes drawn around everything on screen.

Radio and SDR

Tune into about 750 world radio stations by location, or connect your own SDR receiver and map what it picks up.

Director mode

Draw on the map, plan camera moves and record smooth fly-throughs. You can share any view as a link.

Agent access (MCP)

AI agents can query the same live data through a built-in MCP server and add their findings to a shared map.

Run it

Run it yourself

It runs on your own computer, because a small local server fetches the live feeds. That is also why this page is a guide and not the globe itself: a static host like GitHub Pages cannot run that server.

One click

Install Pinokio 8.2 or later, open God's Eye View in Pinokio, then press Install and Start. Works on Windows, macOS and Linux.

Terminal

Needs Node.js 24.14+ or 26.x. Then open http://localhost:4173.

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor
npm run dev

Docker

No Node install needed. Your keys, cache and logs stay in the cloned folder.

git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
docker compose up

If you share it on your network, anyone who can reach it can use your API keys. Set spending limits with each provider before you add paid keys.
